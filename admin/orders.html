Secure setup instructions

In Cloudflare → Workers & Pages → de-shazeb → Settings → Variables and Secrets, add encrypted secrets SAFEPAY_SANDBOX_SECRET_KEY (merchant secret) and SAFEPAY_SANDBOX_WEBHOOK_SECRET (endpoint shared secret), then redeploy. Do not paste either secret into chat or GitHub.

In the SafePay sandbox dashboard, add endpoint https://de-shazeb.pages.dev/api/payments/safepay-sandbox and subscribe to payment.succeeded, version 2.0.0. Use SafePay's test cards only.
